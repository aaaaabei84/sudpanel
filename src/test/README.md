# 测试夹具说明

本目录中的认证样值、固定随机种子、示例设备序列、Demo 名称及构造日志只服务于自动化测试，不得复用到真实认证或业务数据。

- `api/script/signature-fixtures.json` 声明 FICTIONAL 环境变量；专用 fictl 密钥用于固定签名向量，预期结果由独立标准库实现校核。不要为让秘密扫描归零而删除这些向量。
- `ApiScriptSandboxTest` 的重复十六进制 `randomKey` 用于重现随机输出，不是服务密钥。
- TLS 用例在临时目录生成短期证书和私钥；公开 fixture 口令仅保护测试资产。
- privacy/redaction、路径穿越、宿主访问、网络逃逸测试故意带有假 token、私有地址、文件路径或攻击片段，用于验证拒绝和脱敏行为。不能将这些字符串替换成空值或跳过断言。
- 30/38 位循环数字、Long.MAX_VALUE 及相邻数用于数值边界与精度保真，不是真实业务标识。
- 日志解析与文件名测试使用合成 Demo 数据；公开 SDK 状态/字段名称保留以验证兼容性。

运行部分集成测试需要 Node、OpenSSL 或 keytool，并可能启动 loopback 测试服务；这些依赖与动作不属于本轮静态脱敏检查。
