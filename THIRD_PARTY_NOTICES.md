## Distribution boundaries

- No ADB executable, JDK/JRE, DMG, application bundle, company dataset, seed database, local configuration or local dependency cache is included in the source release. Users install their own JDK, Maven, Node/npm and optional Android platform-tools.
- `scripts/build.sh` builds the frontend and a Spring Boot JAR. The JAR contains Maven runtime libraries, including the native SQLite library carried by `sqlite-jdbc`. It does not bundle an ADB executable or Java runtime.
- The frontend imports Geist font files and Lucide icons. Their copyright and license notices are included below. Browser assets generated by Vite are not committed to the source repository.
- If distributing a built JAR, browser assets or a container, ship this document with it; preserve dependency LICENSE/NOTICE files and prepare the notices for the exact resolved runtime artifacts. Keep the applicable MPL-covered source available for the exact version distributed. This source inventory is not a substitute for reviewing a future binary release.
